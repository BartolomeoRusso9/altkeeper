    Provisioning profiles on iPhone
    
    
    Old profiles may remain after renewal. Deleting a profile still needed by an installed app can stop it opening. A verified server-side backup is saved before removal.
    
    
    
    
      
  
      

  
      
    
      Saved profile backups
      
    
      Restore a backed-up profile by UUID. Restoring does not extend its original expiry date. The backup is retained.
      
    
      
    
        
  
        

  
        
    
        Install an app from this PC
        
    
        Choose an IPA. AltKeeper signs it with the configured Apple ID and installs it over Wi-Fi. The Apple ID password must be saved on the server.
        
    
        
      
      
      
      
      
      
      
        These settings are for new installations only. Existing apps and automatic renewal are never modified. A new Bundle ID allows a separate copy; the Apple team suffix is added automatically.
        
      
        
        
        
      
        
    
        
    
        
      
      
    
        
    
        
      
        Confirm new installation

        App ID count is an upper bound; already-registered IDs may be reused. Live Apple quota is not checked here.
