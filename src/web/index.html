How to Connect Discord Webhook

Receive instant alerts in your Discord server if auto-renewal fails

1Open Channel Settings in Discord

Open your Discord server, hover over the text channel where you want to receive alerts, and click the Edit Channel (⚙️) gear icon.

2Create a Webhook & Copy URL

1. Select Integrations from the left sidebar, then click Webhooks.

2. Click New Webhook, name it AltKeeper, and click Copy Webhook URL.

3. The URL looks like: https://discord.com/api/webhooks/123456.../abcdef...

3Save & Test in AltKeeper

Paste the copied URL into the Discord failure notifications field, click Save webhook, and then click Send test notification to verify delivery.

How to Connect a Telegram Bot

Get your Bot Token and Chat ID in under a minute

1Create a Bot & Get Your Bot Token

1. Open Telegram and search for the official verified bot @BotFather.

2. Send the command /newbot, choose a display name (e.g. AltKeeper), and pick a username ending in bot.

3. BotFather will reply with your HTTP API Token (looks like 1234567890:AAFxyz...). Copy and paste it into the Bot Token field.

2Activate Your New Bot (Required)

Click the link to your newly created bot inside BotFather's message and press Start (/start) so the bot is allowed to send you messages.

3Find Your Chat ID

1. Search for @userinfobot (or @GetMyId_bot) on Telegram and press Start.

2. It will immediately reply with your numeric Id (e.g. 987654321).

3. Paste that number into the Chat ID field, click Save bot, and click Send test!
